# 《回环囚地》实现路线与进度表

本文档将正式世界观拆解为可开发、可验收的游戏系统。世界观以 [《回环囚地》正式设定](worldview_zh.md) 为唯一叙事依据。

> 进度核对日期：2026-08-17。状态以当前运行时代码、资源目录和自动测试为准。

## 实现原则

1. 先确保每条世界法则都有可被玩家感知的游戏行为，再补充数值、内容与演出。
2. 存档必须保存会影响选择后果的数据：地图迷雾、居民状态、好感、死亡、领地和轮回进度。
3. 关键抉择必须产生不可逆或代价明确的后果，不能只停留在提示文字。
4. 主角是唯一探索者，NPC 不得自行驱散迷雾或发现地图资源。

## 系统拆解

### 1. 迷雾锁界

目标：未探索格不只是地图上不可见，而是对玩法具有实体边界。

- 数据：每个存档、每张地图维护 `exploredTiles` 位图。
- 触发：仅主角移动时揭开半径内格子；NPC 移动不修改该位图。
- 表现：大地图与世界渲染同时使用迷雾数据；未探索格不显示资源、建筑、敌人和交互点。
- 存档：位图按 4 格压缩为一个十六进制字符写入 `save.json`，探索变化每 5 秒自动保存；旧存档按全迷雾迁移。
- 验收：带灵石的 NPC 单独进入未知区域后，地图不会出现新增探索格。

### 2. 领地、承载力与日常消耗

目标：领地是一种可计算的短暂现实，而非单纯安全区。

- 数据：锚点等级、领地面积上限、现实承载上限、现实稳定度、日进度和累计天数均写入存档。
- 领地面积：I-IV 级上限分别为 `225 / 625 / 1225 / 2025` 格；普通建筑、仓储、围墙和耕地不消耗现实承载。
- 现实承载：I-IV 级上限分别为 `40 / 70 / 110 / 160`；每名实体居民占 `10`，锚点工作台占 `2`，领地内启用的传送点占 `8`。
- 食物：一个游戏日为 `12` 分钟实际游玩时间；每名居民每天消耗 `1` 点带有 `food` 属性的锚点仓库物品，不进行离线结算。
- 稳定度：范围 `0-100`；足额供应每日恢复 `2`，缺粮与旧存档超载会降低稳定度；低于 `25` 时禁止收留和领地扩张。
- 界面：锚点按钮旁持续显示“承载、食物及可维持天数、稳定度、领地面积”，NPC 页签显示领地摘要。
- 验收：承载不足不能收留或启用新传送点；面积超限不能扩张；所有拒绝操作都给出明确原因；控制台 `day` 可立即结算一天用于测试。

### 3. 居民生活与外出

目标：让影子生灵既是生产力，也是需要被保护的对象。

- 工作：闲置 NPC 在领地内游荡；分配采集、建造、种植或搬运任务后产生资源。
- 外出：只有装备对应灵石的 NPC 能在领地外执行工作和战斗。
- 风险：敌人优先攻击领地外实体 NPC；NPC 生命归零后永久消散。
- 工作面板：按领地内生产设施列出独占岗位；当前锚点提供工作台助手岗位，熔炉和农田对象接入后自动显示对应岗位。
- 采集任务：采集石为外出采集许可，可指定木头、特异木头、石头或自由采集；NPC 只会前往主角已探索区域。
- 自卫：装备战斗石的外出 NPC 会攻击附近畸变暗影；未装备时仍会被攻击，但不会主动还击。
- 跟随战斗：跟随 NPC 受击后，装备战斗石且生命高于 30% 时自动反击；无战斗石或低生命时主动躲避。追击和躲避均被限制在主角 500 世界单位的跟随范围内。
- 采集撤退：外出采集 NPC 装备战斗石时自动攻击附近敌人；生命降至 30% 时中断采集并立即返回领地。
- 搬运：每名 NPC 有 10 格随身背包，遵循物品堆叠上限；无法继续装载时自动返回领地并卸入锚点仓库。
- 控制：工作面板可以随时要求 NPC 立即回家；停止任务时如有物资会先返程卸货。
- 验收：取消领地外跟随后，NPC 自动回领地；无灵石 NPC 变为不可交互影子态。

### 4. 锚点死亡与献祭

目标：把世界观中的残酷选择落实为核心失败与成长机制。

- 主角受致命伤时立即冻结战斗和输入，黑屏淡入并显示“锚点死亡，影子代偿”；3 秒后镜头返回现实锚点并打开透明献祭面板。
- 面板列出可献祭居民、好感、性格、与主角的羁绊等级及后果预览。
- 献祭后：居民永久移除；主角传送到该居民所在地图及位置，恢复全部生命，画面淡出黑屏并立即写入存档。好感影响最大生命值留待羁绊数值阶段接入。
- 无居民可献祭：显示“你挥霍完所有人的生命，最终无人为你续命”，播放终焉演出后删除当前存档并返回主菜单。
- 验收：同一名 NPC 不可能在献祭后重新回到当前轮回的居民列表。

### 5. 主线、真相与结局

目标：让探索、领地经营和牺牲选择共同决定结局，而非独立任务清单。

1. 序章：主角坠入囚地，放置第一枚锚点，收留第一位影子。
2. 前期：通过地图迷雾、流浪影子与灵石理解三条基础法则。
3. 中期：关键 NPC 触发记忆片段，揭露其与前轮回献祭的关系。
4. 后期：集齐本源碎片并计算关键 NPC 存活、全图探索、锚点损耗和道具条件。
5. 结局：满足全部条件进入“破界同归”；条件不足进入“孤魂轮回”；无代偿死亡进入“锚点湮灭”。

结局法阵不属于领地建筑：只能作为第四层唯一主线对象生成，不能建造、移动、拆除，也不占用领地面积或现实承载。其状态独立保存为未发现、已发现、已激活、材料不足、仪式就绪和结局触发。

### 6. 四层地图与程序化地形

目标：每层保持明确生态比例，同时避免整张地图只有一个过大的规则色块。

- 层级比例：第一层草地/泥地 `75% / 25%`；第二层草地/泥地/碎石地 `25% / 50% / 25%`；第三层碎石地/沙地 `75% / 25%`；第四层沙地 `100%`。
- 种子数量：以 `地图宽度 / 2` 为基础，并受地图总格数和最小区块限制保护。
- 种子分配：先按层级比例计算各地形种子数量，再随机打散种子类型和出生格。
- 生长：所有存活种子轮流向四方向空格生长，不能侵占其他种子已经占领的格子。
- 清理：单个种子最终占地少于 `100` 格时整块删除，留下的空格由相邻存活种子继续竞争，直到无空格且无过小种子区块。
- 随机锁定：使用 `terrainVariantSeed` 生成；新地图每次不同，保存后读取同一布局，不在运行过程中重新随机。
- 当前限制：最终地形面积接近配置比例，但不强求逐格精确，因为不同种子的可生长空间会产生自然偏差。
- 验收：自动测试检查每层比例偏差不超过 6%，且每个同类地形连通区不少于 100 格。

### 7. 制作、种植与生产

目标：把直接采集物转化为可持续的领地生产闭环。

- 锚点面板：现有页签为锚点仓库、工作台、制作、NPC 列表、工作和采集、科技树；仓库和工作台仅在领地内开放。
- 工作台：种子分解和设施生产分开显示；配方详情显示贴图、材料数量、设施条件和产出。
- 种植：耕地支持五种种子；作物 ID、生长天数和成熟状态写入地图对象；玩家可播种和收获。
- NPC 农务：分配耕地岗位后会优先收获成熟作物，再从锚点仓库选种播种。
- 熔炉：消耗 `2` 个对应矿石和 `1` 个木头生产铁、铜、银、金锭。
- 锯木台：普通木头或特异木头加工为对应木板；设施必须位于领地内。
- 建筑制作：点击建造后关闭面板，透明建筑吸附格子；成功放置后返回面板，右键取消会退回预留材料。
- 当前限制：生产是即时或固定短周期执行，尚无可视化队列、离线生产、燃料槽和产能加成。

### 8. 工具链与自动验证

目标：防止源资源、构建资源和存档模板互相覆盖，减少“换图后仍加载旧图”的问题。

- `assets` 是唯一运行资源源目录，贴图统一使用 PNG；PSD、BMP 和制作中间文件放在 `art_source`。
- `RebuildAndPackAssets` 从源码资源单向生成干净的 `cmake-build-debug/assets`，不从构建目录反向覆盖源码。
- 当前资源模块包括 59 个物品、20 个对象和 9 个地形定义；自然地形贴图数量可自动发现，不再写死变体数量。
- `SceneDataTests` 验证地图存取、旧格式兼容、迷雾存档、NPC 状态、地形变体和程序化世界层。
- `ItemDataTests` 验证物品、建筑、种子和生产设施定义。
- 当前测试状态：`SceneDataRoundTrip` 与 `ItemDefinitions` 均通过。

## 数据与测试清单

- 已写入存档：探索位图、地图地形种子、锚点仓库、蓝图、锚点等级、稳定度、NPC 工作/货物/灵石/生命/好感和农作物状态。
- 尚需写入或补全：献祭历史、好感造成的最大生命修正、主线阶段、本源碎片进度和轮回次数。
- 回归测试：新存档不得继承旧存档 NPC、迷雾、居民死亡或地图状态。
- 边界测试：切图、传送、读取存档、主角死亡、NPC 死亡、领地缩减时均不得产生无效引用。
- 地图测试：固定随机种子验证地形比例、最小区块、无空格和同种存档重载一致性；批量随机种子用于发现极端分布。
- 结局测试：使用固定测试存档分别验证真结局、轮回结局、终焉结局的条件互斥。
