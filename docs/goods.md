### 其他调试指令

| 指令 | 作用 |
| --- | --- |
| `add 怪物 <数量>` | 在鼠标指向的世界坐标生成怪物，单次最多 100 只 |

| `day` | 立即结算一个领地日 |
| `fog` | 清除当前地图全部迷雾并立即写入存档 |
| `debug` | 显示或隐藏全部碰撞边线 |
| `clear` | 清空控制台输出 |
| `help` | 显示控制台帮助 |
