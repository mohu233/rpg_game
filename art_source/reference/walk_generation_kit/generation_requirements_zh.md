# 步行图生成需求

建议逐帧生成，不要一次让 AI 生成整张 4x4。一次生成整图时，AI 很容易画反方向、串帧、补文字、水印、改角色设定。

## 使用方式

每次生成 1 帧，只上传两张图：

1. 角色设定参考图。
2. `anchor_frames` 目录里对应的单帧锚点图。

生成完成后，把 16 张结果按指定文件名放进：

```text
assets/walk_generation_kit/ai_outputs
```

然后运行：

```text
python tools/assemble_ai_walk_frames.py
```

## 总规则

- 只画图 1 的同一个 furry 猫人角色。
- 锚点图只用于姿态、脚底位置、身体重心、尾巴方向参考。
- 不要把锚点图里的骨架线、文字、网格、辅助线画进结果。
- 不要新增衣服、饰品、道具、花纹、背景、阴影。
- 不要改变角色颜色、脸型、耳朵、尾巴、体型。
- 每一帧角色大小一致，脚底对齐，身体居中。
- 侧面帧只画向右，不要画向左。
- 向左走由游戏代码自动镜像，不需要 AI 生成。

## 单帧通用提示词

把 `{帧编号}`、`{方向}`、`{动作阶段}`、`{锚点文件名}` 替换成对应帧信息。

```text
请根据角色参考图和姿态锚点图，生成一张单帧 2D 游戏 sprite。

角色参考图只用于角色外观。
姿态锚点图 {锚点文件名} 只用于动作姿势、脚底落点、身体重心和尾巴方向。

当前帧：{帧编号}
方向：{方向}
动作阶段：{动作阶段}

角色要求：
- 三头身 furry 猫人角色
- 深蓝色外毛
- 青绿色脸部、口鼻、胸腹、爪子、脸颊毛
- 橙色耳内和橙色尾巴尖
- 金色大眼睛
- 大耳朵、圆脸、小口鼻、卷尾
- 每一帧都必须是同一个角色

动作要求：
- 严格跟随锚点图的姿态
- 不要把方向画反
- 侧面帧必须全部朝右
- 脚底保持在同一条地面线上
- 身体保持在画面中心
- 要有真实走路动作，不要只是站立抖动
- 手臂和腿反向摆动
- 按动作阶段表现重心上下起伏
- 尾巴可以轻微摆动，但形状不要大幅变化

输出要求：
- 只输出单个角色 sprite
- 方形画布
- 透明背景最佳，纯白背景也可以
- 不要文字、不要水印、不要骨架线、不要辅助线、不要网格
- 不要地面、不要阴影、不要场景、不要额外角色
- 不要裁切耳朵、脚、手或尾巴
```

## 负面提示词

```text
文字，水印，标签，编号，骨架线，辅助线，网格，背景场景，地面，阴影，额外角色，道具，衣服，饰品，错误颜色，脸型变化，耳朵变化，尾巴变化，方向画反，身体被裁切，缺脚，缺尾巴，模糊，写实，3D，厚涂，比例不一致，角色大小不一致
```
